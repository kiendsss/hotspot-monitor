## 4. 端到端中发现并修复的 Bug（溯源重点）

- **剪报抽屉「原始条目已滚动淘汰」误报**：抽屉原先只查头版预载的最近 60 条，热点引用的条目在池深处时误判为淘汰。
  修复：`/api/items` 增加 `?ids=a,b,c` 精确查询；抽屉改为打开时按需拉取，并增加「检索存档中…」加载态。
- **采编部首次渲染闪现「已停用」**：settings 未返回前 `enabled` 为空对象导致。修复后确认加载完成即显示正确状态（首帧闪现属 SPA 水合前空态，可接受；已通过轮询验证最终态正确）。

## 5. 视觉设计决策（为何独特）

- 报名「热点观察哨·热频日报」+ 号外（EXTRA）红底铅字条，模拟旧报头版
- 热点标题统一红色下划线（报刊墨线变体），点击弹出「✂ 剪报」抽屉（底部锯齿裁切路径模拟剪报边缘）
- 趋势标签做成微微旋转的铅字章：「新上榜」黑框、「↑走热」红框、「↓降温」红虚线框
- 上下两条跑马灯包夹正文，模拟报馆電子字幕条
- 全页网点纹理背景 + 双细线（4px double）分隔，避免现代 SaaS 感
