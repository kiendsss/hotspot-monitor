## 1. 项目背景

用户需要一套「热点监控」工具：持续汇集多来源的信息内容，利用 AI 自动识别、聚合、评估热点，并以可视化方式呈现热点及其趋势变化。整体项目分两个交付物：

1. **网页版（优先）**：先确保网页端功能完整可用，作为日常使用的主入口。
2. **Cursor Agent Skill（第二阶段）**：网页版验收通过后，把「热点扫描」能力封装成 Agent Skill，供 AI Agent 在对话中直接调用。

## 2. 产品定位

一份每天「出版」的 AI 热点情报报刊：

- 多来源采集内容（榜单 / RSS / 手动粘贴）
- AI 聚合识别热点（跨来源去重合并）
- 每次分析生成一期「刊号」快照
- 与上一期快照对比，呈现热点趋势（新上榜 / 上升 / 下降 / 持平）

## 3. 已确认的关键决策

| 决策项 | 结论 |
|---|---|
| 视觉风格 | **复古报刊风**（报头 masthead、号外头条、分栏排版、黑白 + 红墨强调、双细线分隔），不走常规仪表盘路线，保证页面独特性 |
| AI 服务 | **OpenRouter** 统一接入 |
| 默认模型 | `deepseek/deepseek-chat`（免费/低价快速模型档位），设置页可切换 |
| API Key 现状 | 暂无真实 Key，**先以 Mock 模式**跑通全链路，后续在设置页填入 Key 即切换真实 AI |
| 数据来源 | **混合模式**：内置榜单采集 + RSS 订阅 + 手动粘贴内容 |
| Agent Skill 形态 | Cursor Agent Skill（`.cursor/skills/<name>/SKILL.md`） |

## 4. 功能需求

### 4.1 数据采集（混合模式）

| 来源 | 方式 | 说明 |
|---|---|---|
| 微博热搜 | 内置采集 | 服务端抓取公开热搜榜 |
| 知乎热榜 | 内置采集 | 服务端抓取公开热榜 |
| 百度热搜 | 内置采集 | 服务端抓取公开热搜 |
| GitHub Trending | 内置采集 | 解析 trending 页 |
| RSS 订阅 | 用户配置 | 可增删、启停订阅源，定时/手动拉取 |
| 手动粘贴 | 用户输入 | 文章 / 群聊记录 / 推文等文本直接「投稿」 |

非功能性要求：

- 单个来源抓取失败不得影响其他来源（失败隔离），并在界面上展示各源状态
- 抓取请求带合理 UA 与超时（10s）

### 4.2 AI 热点识别（OpenRouter）

- 将采集到的原始条目（裁剪、限流后）交给模型分析
- 输出结构化 JSON：热点标题、摘要、分类、热度（0-100）、关键实体、情感倾向、来源引用
- 跨来源同主题条目聚合去重
- 结构化输出优先使用 `response_format: { type: "json_schema" }`；对不支持该参数的模型自动退化为提示词约束 + 健壮 JSON 解析
- **Mock 模式**：无 Key 时按规则（源热度排序等）生成假分析结果，保证全流程可演示

### 4.3 快照与趋势

- 每次分析生成一期快照（刊号递增）
- 与上一期对比：`新上榜 / 上升 / 下降 / 持平` + 热度变化值
- 匹配规则：标题归一化（去空格/标点、包含匹配）

### 4.4 网页界面（复古报刊风）

| 页面 | 内容 |
|---|---|
| 头版 `/` | 报头（报名、第 N 期、日期、各源状态灯）→ 号外特大头条（Top1）→ 分栏热点版块（衬线大标题、红色热度下划线、铅字趋势标签）→ 底部跑马灯滚动原始条目 → 点击热点弹出「剪报详情」抽屉（摘要/实体/情感/来源/上期对比） |
| 采编部 `/sources` | 内置榜单源开关与立即采集、RSS 订阅管理、手动投稿框 |
| 印务设置 `/settings` | OpenRouter Key、模型选择、Mock 模式开关 |

### 4.5 Agent Skill（第二阶段）

- CLI 脚本：调用本地 API 完成采集 + 分析，输出 Markdown 热点报告
- `SKILL.md`：YAML frontmatter（`name`、`description`），指导 Agent 健康检查 → 必要时启动 dev server → 执行扫描脚本 → 汇报简报

## 5. 约束与注意事项（用户原始要求）

1. 前端页面要足够独特，不要千篇一律 → 复古报刊风 + 纯手写 CSS 设计系统
2. 先完成网页版、确保功能正常使用之后，再开发 Agent Skills
3. 项目必须利用 AI 识别热点，通过 OpenRouter 对接 AI 服务

## 6. 验收标准

- [ ] 网页能正常打开，报刊风格视觉效果独特
- [ ] 能采集多源内容（含失败隔离），手动投稿可用
- [ ] AI（或 Mock）能输出结构化热点结果
- [ ] 快照趋势对比（新上榜/上升/下降/持平）可用
- [ ] 头版 / 采编部 / 设置三大页面交互正常
- [ ] 网页版用户验收通过后，Agent Skill 可被 Cursor Agent 触发并产出热点简报
