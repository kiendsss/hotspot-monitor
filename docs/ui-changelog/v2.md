# UI 焕新 · V2「报纸分区 · Wobble 头条 + Focus 聚读」方案 B

> 日期：2026-09-09 · 范围：头版热点版面（报纸分区大板块 + 全新卡片形态）· 决策人：用户（方案 B）
> 约束：保留 V1-B 纸墨体系（`--paper/--ink/--red`），每批独立验证，久验即释窗转人工

## 本版要解决什么（来自你的原话）

1. **“好几个大板块，每类放一块”**：原 Bento 59 卡等高平铺像后台墙，找不到类别 → 改为按 `HotspotCategory` 自动分区的**报纸大板块**。
2. **“卡片换一种形式，太难看了”**：等高白卡+硬阴影单调 → 换成 **Wobble 头条 + Focus 小卡** 的杂志组合，层次分明。

## 调研来源（按你要求：Firecrawl + Context7）

- **Firecrawl `firecrawl search ... --limit 5` ×2**
  - `newspaper front page layout multiple sections broadsheet grid 2024` → `scribd Page-Design-Grids`：**5 栏网格是分区头版最常用**；`w3.org Electronic Broadsheet`：**“1 个头版 + 若干分区页、平铺”** 是电子大报模型。
  - `editorial news website section blocks 2025` → `Tubik Information, Beautified`：**标题打断分区、正文保持平静节奏**。
- **Context7 `/websites/ui_aceternity` + `/llmstxt/ui_aceternity_llms_txt`**
  - `Wobble Card`：`motion.section onMouseMove` 计算 `x=(clientX-mid)/20`，`translate3d ±x/y + scale 1.02`，`containerClassName/className` 双容器（已取完整 TS 实现）。
  - `Focus Cards`：`hovered: number|null` 状态，`hovered !== null && hovered !== i → blur-[0.8px] opacity-70 scale-0.98`，`hovered === i → shadow 朱红`，聚焦当前卡。
  - `Card Hover Effect / Evervault / Comet` 已对比排除（深色底/3D 与纸色冲突，重度改造）。

## 落地方案：方案 B「杂志导读 · 焦点特写」

```
头版号外（全期头条，不变）
  ↓
按 category 分区（CATEGORY_ORDER: 社会/科技/财经/国际/娱乐/体育/健康/其他）
  每区 = 1 个大板块 .plate
    header .plate-hd：左朱红竖条 + 分区名（0.32em） + 右“n 条 · 热度总和”
    body .plate-body：
      首篇 = WobbleCard（跨整区宽度，放大、摘要全显、鼠标跟随微位移）
      其余 = FocusCards 网格（1/2/3 列响应式，悬停聚焦、邻卡模糊降噪）
```

动效克制：全页仅 Wobble 的 `translate3d` + Focus 的 `blur/opacity`，`prefers-reduced-motion` 已在 `globals.css` 全局熔断；Spotlight/主按钮描边保留但不新增。
