## 后端 / 存储

- `lib/storage.ts`（新增）：Storage 接口 get/set/append 三原语；LocalStorage 读写 ./data/*.json（原子写），VercelKVStorage 用 @vercel/kv（键前缀 hotspot:，未绑定 KV 降级内存 + 一次性告警）；`VERCEL=1` 自动切换
- `lib/store.ts`：全部读写委托 storage；新增 appendDbItems（db-items 视图键，采集增量免整库重写 + 首用播种迁移）；getSettings 合并 env Key/模型并派生 serverless 标志，线上强制关交叉验证防超时
- `lib/env.ts`（新增）：resolveAiConfig 渐进式增强 -- env Key > 设置页 Key > 无 Key Mock；env Key 无视 mockMode 强制真实 AI
- `lib/ai.ts`：APP_URL 读环境变量（OpenRouter HTTP-Referer 归属）
- `lib/verify/cache.ts`：验证缓存改走存储抽象（线上 KV 跨实例共享）
- 路由：analyze/topics-analyze 走 resolveAiConfig，maxDuration 统一 60（Hobby 上限）；settings/health 返回 keySource/effectiveMock（env Key 脱敏不落盘）；collect 用 append 增量入库
- `instrumentation.ts`：VERCEL 上跳过 setInterval 专题调度器（实例生命周期短不可靠，线上改手动追踪）
